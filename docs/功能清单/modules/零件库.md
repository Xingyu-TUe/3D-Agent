# 零件库

**定位**：标准件与企业件的库建设、配置化展示，以及零件几何特征自动识别。  
**用户价值**：按企业配置看到正确零件，并具备可检索、可装配的标准件基础。  
**条目**：去重后 3 条需求/任务，归并为 3 个功能点。
