# 工作台与权限

**定位**：覆盖工作台资源管理、权限与配置、标注平台，以及运营看板入口。  
**用户价值**：让业务与标注同学在统一工作台完成资源管理、批量操作和数据洞察。  
**条目**：去重后 5 条需求/任务，归并为 3 个功能点。
