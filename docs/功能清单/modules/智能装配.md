# 智能装配

**定位**：基于 RPS、约束、避干涉和历史装配 RAG，自动或半自动完成单元装配。  
**用户价值**：标准件少标甚至不标也能装上，复杂场景可避干涉、可调坐标系。  
**条目**：去重后 20 条需求/任务，归并为 5 个功能点。

### 3. RAG智能装配

- **优先级**：P0　**状态**：规划中　**类型**：产品功能
- **迭代周期**：7月
- **产品/业务**：付星宇+王迪
- **关联 PRD**：-

**完成定义（DOD）**

针对焊装夹具中标准零件：气缸，立柱，定位销，能够完成无需用户每个零件手动标注的自动化装配；1. schena设计：主要是零件的几何数据，零件和零件之间的关系。2. 零件约束解析pipeline：能够将零件的接触图转换为约束。（主要问题是，零件和零件之间有多个接触，如何实现过滤）3.数据库架构设计，完成入库pipeline 4.检索：通过id检索对手件，以及对手件的装配面。；1. 历史装配的零件，即使没有装配过，也可以自动装配；历史刷数据；完成线上环境发版；发版到staging环境，可测试；入库数据测评；schema设计适配，数据库建立；1. 明确解析装配结果：零件面，装配约束等；从3d上传零件打开客户端后，自动切到3D产品；完成新的agent，并且上线

- [产品需求] RAG装配上线 （规划中）
