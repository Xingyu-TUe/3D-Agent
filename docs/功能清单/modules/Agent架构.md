# Agent架构

**定位**：夹具/检索/装配 Agent 的运行时、记忆、快捷指令、渲染与第三代可插拔架构。  
**用户价值**：能力可配置、可观测、可发版，焊装高频动作可一键触发。  
**条目**：去重后 17 条需求/任务，归并为 14 个功能点。
