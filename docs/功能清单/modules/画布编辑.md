# 画布编辑

**定位**：3D 画布与模型树上的对象操作、性能与交互一致性。  
**用户价值**：多选、复制、批量改属性和重命名流畅可用，大模型不卡顿。  
**条目**：去重后 7 条需求/任务，归并为 7 个功能点。
