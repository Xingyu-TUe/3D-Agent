# 数据上传解析

**定位**：把 CATIA / CGR / 焊枪 / 人机等数据送入云端资源库，并完成解析、校验与入库。  
**用户价值**：上传即可用：格式正确、位置对齐、分类清晰，减少线下清洗。  
**条目**：去重后 5 条需求/任务，归并为 5 个功能点。

| # | 功能点 | 类型 | 优先级 | 状态 | 验收要点 |

| 4 | 后端数据库迁移 | 支撑能力 | P0 | 规划中 | 确定新的数据库技术栈与数据迁移计划，制定新的数据库结构（新的表和字段） |
| 5 | CRG上传流程重构 | 支撑能力 | P0 | 规划中 | 实现新的上传流程调度，删除旧的不需要的服务。确定是否使用DTF，对上传流程进行配置化设计。 |
