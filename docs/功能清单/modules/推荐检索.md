# 推荐检索

**定位**：按工艺点、属性、对手件和同义词，从公库/企业库召回并排序单元与零件。  
**用户价值**：对话或选点后给出可装配的候选，推荐结果可解释、可回放。  
**条目**：去重后 17 条需求/任务，归并为 10 个功能点。
