地狱裂隙 — 微信开发者工具导入必读
================================

本机固定仓库：D:\RIFT
微信导入目录：D:\RIFT\dist\wechat\

若编辑器里看不到「右下角技能按钮 / 3 分钟 Boss」等新功能，
或文件修改时间很旧 —— 几乎一定是下面三种情况之一：

A. 本机没拉到最新代码（仍停在旧提交）
B. 微信工具打开的是旧路径（如 D:\3D-Agent 或很久前解压的文件夹）
C. 打开了仓库根目录，而不是 dist\wechat\


正确操作（按顺序做）
--------------------
1）在本机双击：
     D:\RIFT\同步到本机.bat
   （没有 D:\RIFT 时，先从 GitHub 下载该 bat 再运行）

2）再双击：
     D:\RIFT\检查是否最新.bat
   应显示「代码已与远程同步」且「微信包含主动技能UI」

3）双击：
     D:\RIFT\打开微信目录.bat
   会打开 D:\RIFT\dist\wechat\

4）微信开发者工具：
   - 关闭旧项目
   - 「导入」或「打开」→ 选 D:\RIFT\dist\wechat\
   - 该目录下必须直接看到：
       game.js
       game.json
       project.config.json
       Assets\
   - 点「编译」
   - 仍旧：详情 → 本地设置 → 清缓存 → 全部清除 → 再编译


如何确认已是新版
----------------
进战斗后看右下角是否有两个技能按钮（技能 / 大招）。
倒计时约 3:00；约 30 秒会出现小 Boss。


不要做的事
----------
- 不要长期用整个源码仓库根目录当小游戏目录
- 不要继续打开 D:\3D-Agent（旧路径）
- 不要只靠「更新游戏.bat」从 CDN 拉包（可能被缓存成旧 zip）
  优先：同步到本机.bat → 本地 npm run build:wechat
