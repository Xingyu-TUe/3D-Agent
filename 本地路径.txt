## 若在你自己的电脑上没有这份代码

```bash
git clone -b cursor/hell-rift-wechat-game-b0ee https://github.com/Xingyu-TUe/3D-Agent.git
cd 3D-Agent
npm install
npm run dev
```

然后把 `local-paths.json` 里的 `"root"` / `"absoluteRoot"` 改成你本机路径，例如：

- Windows: `D:/Games/3D-Agent`
- macOS: `/Users/你的用户名/3D-Agent`
