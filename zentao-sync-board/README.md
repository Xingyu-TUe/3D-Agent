# 迭代同步看板 · 原型

## 快速预览

```bash
cd zentao-sync-board
python3 -m http.server 5173
```

浏览器打开：http://localhost:5173

- 按**迭代（执行）**切换查看
- 按**开发人员**汇总：未开始 / 进行中 / 已完成的**任务数 + 预估工时**
- 顶部合计指标与完成率
- **人员汇总表** / **任务明细看板** 双视图
