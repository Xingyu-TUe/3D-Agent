同步动态

    统计口径

    • 未开始 = wait；进行中 = doing，已暂停（pause）一并计入进行中。
    • 已完成 = done，已关闭（closed）计入已完成，并归到完成人，而不是「Closed」账号。
    • 已取消不计入柱状图和合计。父任务不与子任务重复计算。
    • 工时默认是禅道预计工时（estimate）。柱状图可切换为预估工时对比。
    • P0+P1 = 禅道优先级 pri 为 1 或 2（1 最高）。工时完成率 = 已完成预计工时 / 合计预计工时。
