# 角色素材说明（概念图 → 可运行资产）

## 关于「512×512 AAA 手绘」与微信可玩性

完整规格（512×512 × 8 方向 × 全动画）单职业约数百 MB 未压缩贴图，**无法放入微信小游戏主包**。

本仓库采用：

| 项目 | 值 |
|------|-----|
| 运行时帧 | **128×128**（`FRAME=256` 可重生） |
| 布局 | 行=8 方向，列=帧 |
| Pivot | 脚底对齐，三角色一致 |
| 阴影 | `shadow.png` 单独输出 |
| JSON | 每动画一份，可无改代码替换高清 PNG |

**替换高清流程**：保持文件名 / JSON 的 `frames`·`directions`·`pivot` 比例不变，用外部 AAA 手绘覆盖 `idle.png` 等即可。

## 概念还原清单

- 德鲁伊：白须老人、鹿角、狼皮披肩、绿核巨杖、狼灵、藤蔓/绿粒子
- 猎人：绿披风兜帽、长弓箭袋、轻甲、拉弓射箭与拖尾
- 法师：紫黑金纹袍、水晶杖、奥术球、法阵与紫粒子

## 命令

```bash
npm run generate:characters
FRAME=256 npm run generate:characters   # 更清晰（包体更大）

```
