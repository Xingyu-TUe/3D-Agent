# Assets

本游戏所有视觉元素均由 **Canvas 程序化绘制**（角色、怪物、技能特效、地面、UI），
**不依赖任何图片/音频美术素材**，因此本目录默认为空。

这样设计的原因：
- 完全原创世界观，无任何第三方版权素材（含暴雪等）。
- 微信小游戏包体更小，加载更快。
- 便于以纯代码方式迭代美术风格。

## 后续接入真实素材（可选）

若未来要接入贴图 / 音效，建议按如下结构组织，并在 `src/Utils/AssetLoader.js`（需自行新增）中统一预加载：

```
Assets/
  images/    # 角色、怪物、UI 贴图 (png/jpg)
  audio/     # 背景音乐、音效 (mp3)
  atlas/     # 图集与配置
```

微信小游戏中通过 `wx.createImage()` / `wx.createInnerAudioContext()` 加载。
